# Demo and pilot success

Target an unaided viewer correctly identifying **V2 and the remaining CRM warning within 30 seconds**, with zero previous decisions presented as current. Time from opening the V2 view to the complete correct answer. Record wrong answers, prompts and timeouts. The first pilot compares this task with the geologist’s current process on equivalent permissioned redacted or synthetic cases. Timing and baseline are pending.

The five-minute rehearsal starts with an empty database and ends with separate V1 and V2 decisions. Verify a V1 hold for the ID mismatch and blank exceedance, then a V2 comparison showing both resolved and the CRM warning ongoing. Confirm PDF bytes, SHA-256 hashes, sample custody and the retained V1 decision. Record an investigation disposition on V2. Repeat the demo offline and test alternate input errors separately.
